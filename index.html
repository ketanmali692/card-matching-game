❓ Help

How to play

  • Tap a card to flip it.
  • Find two cards with the same symbol to make a match.
  • Match all pairs before the timer or flips run out.
  • Use hints to see one matching pair for a moment.

Scoring

  • +100 points for every correct match.
  • -25 points for every wrong pair.
